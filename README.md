# RHA Lab website

Research in Human Airway Mucosal Immunology Lab, Yonsei University College of Medicine.

Static single-page site served by GitHub Pages from the `main` branch root.

## Editing content

All content lives in `index.html`:

- Korean UI strings: the `T.ko` object near the top of the `<script>`.
- Research topics: `topics`
- PI career and awards: `career`, `awards`
- Members: `memberGroups`, `interns`, `staff`, `alumni`
- News: `news` (newest first)
- Publications: the `P` block, one paper per line as `authors|title|journal|year|volume(issue):pages|f or c` (`f` = first/corresponding, `c` = co-author)
- Selected papers: `featured`
